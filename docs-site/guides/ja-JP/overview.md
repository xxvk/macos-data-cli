## mpia とは

`mpia` の中核となる製品形態は、エージェントと開発者向けのローカル macOS データアクセス CLI です。特定のエージェントベンダーやクライアントに依存せず、検出可能で機械可読な共通コマンドコントラクトを通じて、さまざまなエージェントが macOS データへ簡単にアクセスできます。内部では Apple の公開フレームワークを優先し、公開フレームワークがない場合は、フェイルクローズの読み書き境界を持つ、範囲を絞ったローカルアダプターを使います。ローカルでのみ動作し、連絡先・メール・写真・メモをアップロードすることはありません。

## インストールと TCC

**Homebrew Cask が第一優先かつ最も推奨するインストール方法です。**

```bash
brew tap xxvk/tap
brew install --cask mpia
```

バンドル識別子は `com.xvk.mpia.cli` です。保護された macOS データへアクセスする場合は、連絡先・カレンダー・リマインダー・写真・フルディスクアクセス・オートメーションの必要な権限を、Homebrew でインストールした `mpia` app バンドルに付与してください。TCC 権限の付与時に生の実行ファイルで代用してはいけません。

## macOS デモ App（計画中）

mpia の権限、リソース検出、保護された読み書きフローを視覚的に体験できる SwiftUI macOS デモ App を今後提供する予定です。正式なインターフェースは引き続き CLI と機械可読コントラクトです。

## その他の説明

### 安全境界

- 読み取り専用コマンドはユーザーデータを変更しません。
- 書き込みには明示的な `--dry-run`（プレビュー）または `--apply`（永続化）が必要です。
- 破壊的操作には `--apply` に加えて正確な確認フレーズが必要です（例：`DELETE CONTACT`）。
- 曖昧な一致は報告され、黙って自動選択されることはありません。
- `outcome_unknown` の結果は自動で再試行してはいけません。

### 機械可読コントラクト

すべてのコマンドは JSON を返します：

```json
{ "ok": true, "contractVersion": "0.1", "data": {} }
```

次のコマンドでコマンドレジストリを取得できます：

```bash
mpia GET "/agent/manifest"
```
