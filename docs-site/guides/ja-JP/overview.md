## mpia とは

`mpia` はエージェントと開発者向けのローカルな macOS データアクセス層です。Apple の公開フレームワークを優先し、公開フレームワークがない場合は、フェイルクローズの読み書き境界を持つ、範囲を絞ったローカルアダプターを使います。ローカルでのみ動作し、連絡先・メール・写真・メモをアップロードすることはありません。

## 安全境界

- 読み取り専用コマンドはユーザーデータを変更しません。
- 書き込みには明示的な `--dry-run`（プレビュー）または `--apply`（永続化）が必要です。
- 破壊的操作には `--apply` に加えて正確な確認フレーズが必要です（例：`DELETE CONTACT`）。
- 曖昧な一致は報告され、黙って自動選択されることはありません。
- `outcome_unknown` の結果は自動で再試行してはいけません。

## アダプター

連絡先、メール（読み取り専用）、カレンダー、リマインダー、写真、メモ、ショートカット、Safari は、それぞれ明示的な権限と読み書き境界を維持します。

## インストールと TCC

バンドル識別子は `com.xvk.mpia.cli` です。0.9.0 で `macos-data` から改名したため、macOS はこれを新しいアプリとして扱います。連絡先・カレンダー・リマインダー・写真・フルディスクアクセス・オートメーションは再認可が必要です。TCC 認可済みの読み取りには、生のバイナリではなく署名付き app バンドルを実行してください。

## 機械可読コントラクト

すべてのコマンドは JSON を返します：`{ "ok": true, "contractVersion": "0.1", "data": … }`。コマンドレジストリは `mpia manifest --format json` で取得できます。
